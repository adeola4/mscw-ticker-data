# MSCW Ticker Data

Live data feed for the MapleStory Classic World Top-100 trade ticker.

- `data.json` — current board (refreshed every 15 min by an aggregator on the ticker host)
- `history/` — rolling 14-day snapshots

Source: aggregate statistics computed independently from the public kerning.gg
listing feed (in-game smega-derived; crawling permitted per robots.txt).
Not affiliated with Nexon or kerning.gg. Market information only — no RMT.
